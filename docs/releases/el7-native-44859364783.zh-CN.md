# CentOS 7.9 x86_64 原生安装候选包验收

交付标签为 `el7-ambari-native-rc-44859364783`。归档含三个分卷、63 个应用 RPM 和 287 个系统依赖 RPM。下载所有分卷及校验清单，按 INSTALL.zh-CN.md 核验后解包。[分卷及内容校验工作流](https://github.com/wenna/ambari-bigtop-centos7-build-public/actions/runs/44859364783)

HBase 2.4.17 来自 Bigtop 3.3.0 的固定源码版本。构建容器使用非零 UID，交付仓库包含基础包、Master 和 RegionServer，供 YARN Timeline Reader 安装内嵌 HBase。三个 RPM 的独立摘要见 ats-hbase.sha256。[HBase 构建记录](https://github.com/wenna/ambari-bigtop-centos7-build-public/actions/runs/44847222340)

三台测试主机禁用 SSH root 登录和密码认证。控制机以 `clusterops` 公钥登录，三个会话的 UID 均为 1000。脚本使用非交互 sudo 安装 Ambari、配置 Server 和注册 Agent。浏览器通过手工注册模式安装七项服务并到达 Summary。Ambari 共完成 44 个安装任务、20 个启动任务和 7 个服务检查，后台逐项核验了三台主机的组件状态。[SSH 身份、页面流程及任务记录](https://github.com/wenna/ambari-bigtop-centos7-build-public/actions/runs/44861827111)

生产部署时，由现场预置普通部署账号、公钥、受管 sudo 授权和软件包只读挂载。运维人员从部署账号直接运行脚本。集群的 SSH 策略、磁盘、业务容量和故障域须按现场验收。

另一套三节点 HA 集群通过 Ambari Blueprint 复测了 NameNode 与 ResourceManager 主备切换、HDFS 读写、YARN WordCount、Hive on Tez、Spark on YARN cluster 模式及 PostgreSQL Metastore。Hive 和 Spark 均返回 alpha=5、beta=7。前一轮 Spark ApplicationMaster 曾以退出码 13 结束，重建后同一作业通过，第一次失败的根因尚未确认。浏览器安装验收与 HA 工作负载验收使用独立集群。[HA 和作业成功记录](https://github.com/wenna/ambari-bigtop-centos7-build-public/actions/runs/44897695080) · [前一次 Spark 作业记录](https://github.com/wenna/ambari-bigtop-centos7-build-public/actions/runs/44893167374)
